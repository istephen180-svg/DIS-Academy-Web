# DIS Academy Web Frontend 2.3.3

This is a targeted frontend update based on the tested DIS Academy 2.3.2 baseline. It adds the lesson type to the Upload Centre, persists attachment metadata through the API, and adds assessment submission review and teacher marking inspection. The existing application modules are otherwise retained.

Production API base URL remains configured in `api-config.js`. Preserve the existing Render environment variables and production database.
